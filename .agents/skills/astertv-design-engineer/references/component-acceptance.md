# AsterTV component acceptance

## Foundations

Use the canonical token file. The television surface uses the accepted
ink/charcoal, warm cream, champagne gold and jade language, not the navy/cyan
HomeLab web-application guide.

All Aster-owned identity and interface artwork is SVG-first. A raster is
acceptable only as a deterministic export from the exact approved SVG for one
recorded placement, with both hashes and the fixed consumer size recorded.
Runtime or raster-to-raster resizing fails acceptance. Media-provider artwork
is content rather than reusable interface artwork.

## State checklist

| Family | Minimum evidence |
|---|---|
| Identity/icons | light, dark, small, correct context, forbidden-use example |
| Background/hero | image/no-image, text-safe region, low-resolution art, no hard split |
| Top/side rail | rest/focus/current, first/last, expansion, return focus |
| Pills/buttons | identical geometry at rest/focus/pressed/disabled; long label |
| Artwork | poster/square/cast/landscape; rest/focus/current/watched/unwatched/missing/error |
| Players/dialogs | Play/Resume/Trailer distinction; busy/offline/error/recovery |
| Lists | empty, long-scroll, unavailable dependency, more than eight seasons |
| Page | 1920x1080 and Jen-class behavior; complete focus graph |
| Remote | phone portrait/landscape, touch/voice/keyboard/equipment, connection loss |

Synthetic fixtures must exclude private camera frames, account names, watch
history, credentials and household-specific content history.

Tests establish consistency, not taste. Record candidate versus accepted status
and the product owner's decision.
