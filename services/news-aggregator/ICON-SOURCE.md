# News Digest web app icon

The 180 px and 512 px `static/app-icon-*.png` files are rendered from the
Aster Home v2 vector master in the Brand Asset Library:

`brands/aster-home/working/2026-10-13-aster-home-v2-reconstruction/family-candidate-2026-10-14/SVG/04-news-digest.svg`

For the web app export, set the SVG viewBox to `55 40 1140 1140` and place an
opaque `#D1C1AA` rectangle behind the existing artwork. Render at exactly
180 × 180 and 512 × 512 pixels. This crops the master’s transparent outer
margin while keeping the compass and newspaper visible, and prevents Safari
from adding a white backing tile. The SVG master remains in the asset library.
