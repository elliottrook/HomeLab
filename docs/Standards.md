# HomeLab Engineering Standards Moved

`Project-Creation-Standard.md` is the current source of truth for the lab
ethos, authorization streams, pre-start risk assessment, milestone gates,
documentation rules and the integration checklist.

This document was retired 2026-09-15 because it duplicated a thinner, less
current subset of what `Project-Creation-Standard.md` already maintains as
the adopted repository process (its own core principles, documentation rules
and operational workflow sections had fallen out of sync with the fuller
standard). Do not add process or standards updates here; update
`Project-Creation-Standard.md` instead. The former content remains available
in Git history.
