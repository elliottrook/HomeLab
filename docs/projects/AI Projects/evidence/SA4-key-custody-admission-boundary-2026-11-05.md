# SA4 key-custody admission boundary — 2026-11-05

## Result

The next credential stage now has a pure, source-only admission validator. It
accepts only a three-role candidate in the already approved order:

1. `owner-approval` on the human owner device;
2. `ai-pam-grant` in the AI-PAM broker custody domain; and
3. `independent-observer` on the Proxmox observer surface.

Each role must name its fixed custody domain and signer location, a distinct
signer identity and a canonical RSA-2048 public key. All three public-key
digests and signer identities must be distinct. The candidate must attest that
each key was generated by its external custodian, was not exported, was not
read by Codex and cannot be nominated at runtime. Any reused key or signer,
changed role/domain/location, private-material exposure, extra field or effect
claim fails closed.

An accepted candidate yields only three public-key digests and
`ready_for_owner_review=true`. It explicitly returns
`ready_for_installation=false`, accepts no private material and grants no
effect. It cannot generate, read, install or sign with a key.

Four focused tests cover the exact candidate, reused identity, private
exposure/runtime nomination and role/envelope mutation. The complete SA4 suite
passes **72/72**.

## Boundary

No candidate keys exist yet. The installed LXC 104 framework is unchanged and
its three key slots remain empty. The validator does not authorize Keychain,
private-key, AI-PAM or Proxmox signer access; it does not update the compiled
trust registries and cannot make measurement, checkpoint or repair eligible.

## Next gate

The three custodians must independently create or nominate their own signing
identities and supply only canonical public keys plus custody attestations.
That credential operation requires exact approval because it creates and/or
accesses signing identities in three distinct security domains. The resulting
public-only candidate must pass this admission validator and owner review
before any source trust registry or installed file may change.
