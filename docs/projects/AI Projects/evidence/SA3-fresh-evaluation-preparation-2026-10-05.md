## Role separation within this window

Jason's one-window instruction controls the user experience. No separate ChatGPT
project or other Codex window is required. This coordinating thread can assign
fresh supporting agents with no inherited conversation to distinct roles:

- Custodian: authors cases/keys, sees this protocol and source categories but no
  development model answers or scores; does not edit evaluated code.
- Reviewer: independently checks the proposed cases, keys and rubric before model
  execution; sees no candidate responses; issues a content-free acceptance receipt.
- Evaluator: this coordinating thread runs only a sealed case bundle, with keys
  withheld, after the separate connected-run approval.
- Scorer: a fresh supporting agent receives sealed outputs with mode labels masked
  and the frozen keys after execution; cannot change cases, rerun or edit the model.

Distinct agent/task IDs provide procedural separation. They share a filesystem
and underlying model family; this is not access isolation, independent human review
or an external audit. Report correlated-reviewer and synthetic-case limitations.
Author/reviewer outputs to this thread must contain counts, issues and receipts,
not case text or keys. If role separation cannot be demonstrated, do not claim it.
