# S1 representative routing holdout — incomplete close-out

Date: 2026-10-03  
Status: **CLOSED INCOMPLETE; EVIDENCE PRESERVED; EVALUATION BLOCKED**

## Decision

The collection effort is closed at its current evidence level. The nine accepted
bundles remain immutable historical evidence. No request, label, receipt or
accepted bundle has been deleted, rewritten, relabelled, moved to a different
stratum, or supplied to a router, model, tool, evaluator or training path.

This is not a failed safety result and it is not an evaluation result. It is a
feasibility finding: the no-suggestion, human-label workflow produced useful
personalized examples, but did not reach the frozen holdout's required balanced
sampling shape before the project was redirected.

The final strata are the human-accepted labels, rather than the conversational
batch names. They cannot be silently reassigned to satisfy quotas.

## Why evaluation cannot proceed

The frozen `PLAN.md` permits a run only after exactly 50 accepted families with
five in each stratum and at least ten adverse-constraint cases. The preserved
corpus has 45 accepted families, an uneven stratum distribution, and no case
with a frozen adverse-constraint tag (`negation`, `changed-intent`,
`unavailable-dependency`, `privacy-locality`, or `misleading-keyword`).

Adding agent-authored requests, inferred labels, automatic stratum reassignment,
or post-hoc adverse tags would destroy the no-suggestion provenance and would not
repair this experiment. It would require a new, separately versioned protocol
and newly accepted human evidence. That work is deliberately not started here.

The bundle validator checked each accepted bundle's syntax, hashes and frozen
vocabulary. Those checks do not verify human identity, semantic privacy,
no-suggestion provenance or routing correctness. All authorization, confidence,
privacy-semantics and evaluation claims remain false.

## Disposition and successor work

S1 remains available as **personalized collection feasibility evidence only**. It
cannot select a router, calibrate confidence, train a model, promote a policy, or
support a shadow/production route. The frozen packet files are left unchanged so
their hashes continue to verify the accepted bundle records.

Stream A's next bounded task is **SA3 incident-corpus readiness**: strengthen the
empty, local-only incident intake contract and record which required evidence is
still absent before any Qwen/provider comparison. It uses no S1 request text,
adds no human labels, makes no model call and has no production effect. See
[`../../evidence/SA3-corpus-readiness-discovery-2026-10-03.md`](../../evidence/SA3-corpus-readiness-discovery-2026-10-03.md).

## Reopening

Reopening S1 requires Jason to approve a new named protocol and custody/retention
decision. It must preserve this corpus as incomplete historical evidence, use
new human-authored cases and labels, freeze new quotas before collection, and
require a separate evaluation approval after collection. It must not amend this
closed manifest or reinterpret the existing records.
