# V3b execution approval gate

Status: **approval not requested for this release**

A future exact approval may authorize staging the frozen V3b files, creating and
validating the new ISO and stopped VM121, then one bounded offline boot and evidence
retrieval. Any mismatch ends the window; there is no retry.

It would not authorize accepted-corpus access, network attachment, credentials,
package installation, changes to VMs118–120, cleanup/destruction, production
deployment, permission/policy change or Git push. Failure leaves VM121 stopped and
retained.
